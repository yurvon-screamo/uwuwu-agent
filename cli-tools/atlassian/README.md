# atlassian-cli

Bun-based CLI for Jira & Confluence, backed by the `mcp-atlassian` MCP server via `mcporter`.

## Install (global, via `bun link`)

```bash
cd agent/cli-tools/atlassian
bun install          # installs commander + mcporter
bun link             # registers `atlassian` on PATH
```

After linking, the command is available globally:

```bash
atlassian --help
atlassian jira-search --jql 'assignee = currentUser()'
atlassian confluence-get-page --title "Some Page" --space-key DEV
```

## Configuration

All configuration lives in `.env` next to `bin.ts`. See `.env.example` for the full list.

| Var | Required | Purpose |
| --- | --- | --- |
| `CONFLUENCE_PERSONAL_TOKEN` | yes | Personal Access Token for Confluence |
| `JIRA_PERSONAL_TOKEN` | yes | Personal Access Token for Jira |
| `CONFLUENCE_USERNAME` | yes | Confluence account email |
| `JIRA_USERNAME` | yes | Jira account email |
| `CONFLUENCE_URL` | yes | Confluence base URL |
| `JIRA_URL` | yes | Jira base URL |

Process env always overrides `.env`:

```powershell
$env:JIRA_PERSONAL_TOKEN = "..."; atlassian jira-get-issue --issue-key PROJ-123
```

## Layout

```
atlassian/
  atlassian.ts     # MCP server source (generated by mcporter — do not edit)
  bin.ts           # entry: loads .env, validates, runs atlassian.ts
  .env             # real values (gitignored)
  .env.example     # template
  package.json
```

## Dependencies

- Runtime: [bun](https://bun.sh/)
- Underlying MCP server: [`mcp-atlassian`](https://pypi.org/project/mcp-atlassian/) — must be installed and available on PATH (`uv tool install mcp-atlassian`, `pipx install mcp-atlassian`, or similar).

## Notes

- `atlassian.ts` is auto-generated. To regenerate, use `mcporter` against the upstream MCP server spec.
- `.env` is gitignored; never commit real tokens.
