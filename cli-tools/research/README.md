# research-cli

CLI for searching public code on [grep.app](https://grep.app) via the `mcporter` runtime. Useful as a complement to library docs lookup (`ctx7`) and web search (`tvly`).

## Install (global, via `bun link`)

```bash
cd agent/cli-tools/research
bun install
bun link             # registers `grep-github` on PATH
```

## Usage

```bash
grep-github searchGitHub --query "useState cleanup"
grep-github searchGitHub --query "spawn\\(.*cargo" --use-regexp true --language rust
grep-github searchGitHub --query "TODO" --repo owner/repo --match-case true
```

### Flags

| Flag | Purpose |
| --- | --- |
| `--query <pattern>` | Literal code pattern (required) |
| `--language <lang>` | Filter by language (rust, python, typescript, ...) |
| `--use-regexp true` | Enable regex mode. Prefix query with `(?s)` for multiline. |
| `--repo <owner/repo>` | Restrict to a specific repository |
| `--match-case true` | Case-sensitive match |
| `--match-whole-words true` | Whole-words only |

Searches match **literal code**, not keywords. Search for actual snippets you want to find in real-world codebases, not English descriptions.

## Layout

```
research/
  grep.ts          # MCP-backed CLI (generated by mcporter — do not edit)
  package.json
```

## Dependencies

- Runtime: [bun](https://bun.sh/)
- `grep.ts` talks to the public grep.app HTTP MCP endpoint — no auth required.
