# Visual Diagrams

Форма следует содержанию. Это не «кубики со стрелками», а полная выразительность веба внутри дока uwuwu.

## Как писать

- **Нод-графы (архитектуры, конвейеры, связи)** → статичный **SVG/inline-HTML** (dagre-раскладка руками или визуальный редактор; JS-движки на SiYuan v1 не исполняются)
- Текстовые блок-схемы/сиквенсы → mermaid (инлайн; SiYuan рендерит mermaid-фенсы нативно)
- Возьми `assets/template-vesper.html` (тема для плоского HTML) — палитра + типографика, макет и фигуры свои под содержание
- Без JS/CDN/анимаций: SiYuan v1 не исполняет JS в html-блоках (интерактив афин-эпохи не переносится)
- Живые примеры в проде: «uwuwu: Стек и архитектура» L0/L1 (статичные HTML-блоки, пары «⁂ diagram:* + html»)

## Два слоя визуала (онтология выбора)

Выбор движка = вопрос «какой слой», не «какая библиотека»:

1. **Визуал в моменте** — объяснить конкретную вещь сейчас: сиквенс в теле задачи, механизм в статье опыта, инцидент в ранбуке. Движки: cytoscape (интерактив-ноды), mermaid (сиквенсы/флоу), голый Vesper-HTML (степперы/таймлайны/кастом). Не обновляется никогда — устарела вместе с контекстом, так и задумано; порог создания минимальный.
2. **Модель проекта (C4)** — каноническое описание структуры, живёт годами: элемент, связь, deployment-уровень. Только LikeC4: док «Модель (LikeC4)» в папке проекта (источник истины), в Стек-доке — только рендер-вью + линк на модель. Обновление: правка DSL → likec4_refresh → замена эмбеда. Стабильные id элементов = линки между вью и доками.

Cyotscape-эмбеды в Стек-доках — переходное наследие: по мере появления LikeC4-моделей заменяются вью модели (прецедент: true-washing).

## Нод-графы: Cytoscape.js + dagre (архив афин-эпохи)

> ⚠ **На SiYuan v1 мёртв**: JS в html-блоках не исполняется — CDN/интерактив/canvas не рендерятся. Секция сохранена как история афин-эпохи и справочник раскладки-идей; канон SiYuan — статичные SVG/inline-HTML (см. «Как писать» и «Возможности»).

Дефолт для графов из нодов/связей/зон. Layout считает dagre (никакой ручной геометрии — класс багов «стрелки поехали» закрыт), рендер и интерактив — cytoscape (canvas).

- **CDN (основной путь, 6КБ)**: три скрипта с **unpkg** (jsdelivr в песочнице блокируется!), ПОРЯДОК важен — dagre → cytoscape → cytoscape-dagre (саморегистрируется):
  ```html
  <script src="https://unpkg.com/dagre@0.8.5/dist/dagre.min.js"></script>
  <script src="https://unpkg.com/cytoscape@3.30.4/dist/cytoscape.min.js"></script>
  <script src="https://unpkg.com/cytoscape-dagre@2.5.0/cytoscape-dagre.js"></script>
  ```
- **Инлайн-фоллбэк** (offline-гарантия): `assets/cyto-dagre.min.js` (482КБ, cytoscape+плагин одним IIFE) вместо трёх src. Пересборка: `bun build entry.js --minify` c `cytoscape.use(cytoscapeDagre)`.
- **Зоны** = compound-ноды (`parent: "ZONE_ID"` + класс `zone`): dash-рамка, uppercase-лейбл сверху; dagre учитывает их при раскладке. Промежуточные ноды-зоны без контента прятать (`style visibility hidden`) не нужно — просто не давай label.
- **Канвас большой**: `#cy {width:100%; min-width:1200px; height:92vh; min-height:1000px}` + `window.resize → cy.resize(); cy.fit(undefined, 36)` — embed разворачивается на весь экран юзером, канвас перерастягивается.
- Стили — наша палитра классами (`core` персик / `gw` лаванда / `store` мята / `actor` стальной; рёбра `ea/ed/ew/eg`); тап по ноде — подсветка closedNeighborhood, остальное `.dim`.
- Гоча: `cytoscape-dagre` не тянет рёбра compound-нод («dagre can't handle edges on compound nodes») — связи только лист-к-листу.

## LikeC4: модель-как-код в вики (много-вью архитектуры)

Когда архитектура = **модель** (стабильные id элементов, несколько связанных вью, deployment-уровень, статические линки) — не разовая диаграмма. DSL-исходники живут **в вики** (воркспейс SiYuan), рендер — самодостаточный веб-компонент.

- **Хранение (канон)**: док `Модель (LikeC4)` в папке проекта; исходники — фенсами ` ```c4 ` (specification/model/views/deployment отдельными секциями). В Стек-доке — только эмбеды + линк на модель-док. Никаких копий исходников в двух местах.
- **Конвейер**: `python3 ~/uwuwu-agent/tools/likec4_refresh.py <модель-docId> <стек-docId> --view <id>` — извлекает фенсы → нативный `likec4 gen webcomponent --no-use-dot` (CLI установлен `bun add -g likec4@1.60.0`, graphviz не нужен; фоллбэк — `bunx likec4`) → HTML-обёртка → маркер-адресная вставка/замена `⁂ diagram:likec4-<view>`. Каждый view = отдельный эмбед (2.6МБ, все вью зашиты в один wc.mjs).
- **HTML-каркас**: `<likec4-view view-id="…" color-scheme="dark">` + инлайн-JS; контейнер `display:block; width:100%; min-width:1200px; height:92vh; min-height:1000px`.
- **Гочи**: атрибут `view-id` (kebab!), НЕ `viewid` — при невалидном пропе компонент **молча фоллбэчит на view 'index'** + `Invalid props` в консоли (и одиночный `Invalid props` в рендере бывает шумом первого цикла — суди по наличию контента вью); аффина отдаёт фенсы как ` ``` c4` с пробелом — regex с ` ?c4`.
- CDN не нужен — генерат самодостаточен (0 импортов, React внутри, shadow DOM); output нативного CLI байт-паритетен контейнерному (проверено 27.10).
- **Выбор**: cytoscape — разовые нод-схемы/конвейеры с кастомным интерактивом; LikeC4 — живая модель проекта с navigation между вью, element-details, deployment-уровнем.

## Возможности (SiYuan v1, live-check 06.11.2026)

- html-блок SiYuan принимает HTML в потоке дока: inline-styles, SVG, `<div>`-макеты — рендер нативный
- **JS не исполняется** (нет sandbox-iframe афин-эпохи) — диаграммы статичные; анимации/степперы/CDN (unpkg/jsdelivr) — не работают, не закладывай
- афин-доки с `embed_html`-блоками (JS/CDN) при миграции 04.11 потеряли интерактив — существенное дублируется текстом (см. канон «Стек и архитектура»)

## Правила выживания (единственные ограничения)

1. **Без внешних CDN** — док должен рендериться и через годы, всё инлайн
2. **Текст вокруг несёт смысл** — в export/embed диаграмма = плейсхолдер; важное дублируется словами в теле
3. Качество — ui-скилы (`rules-ui`, `architect-ui-ux`): без AI-слопа, типографика, дисциплина

## Вставка и жизненный цикл

Cli-канал — `uwuwu-cli task body` с фенсами ` ```html_embed [имя] ` (SiYuan v1, конвертация реализована):

- **анонимный фенс** — html инлайн в тело (живой HTML-блок в месте фенса);
- **именованный непустой** — пара «маркер-абзац `⁂ diagram:<имя>` + html»: append обновляет диаграмму в доке по маркеру (replace/insert/delete — пустой фенс удаляет), `--replace`/`--replace-section`/create пишут пару как есть;
- живой html-блок с той же смысловой нагрузкой — самодостаточный HTML без пустых строк (пустая строка разрывает html-блок Lute — cli откажет на входе); правка вне тел задач — руками в UI или `tools/wiki_ops.py` block-surgery;
- существующие живые html-блоки тела переживают `--replace`/`--replace-section` (экспорт ядра отдаёт их сырым HTML — round-trip не ломает блок); live-check ядра 3.8.10, 06.11;
- ⚠ SiYuan v1 **не исполняет JS** в html-блоках — диаграммы статичные (SVG/inline-styles), интерактив афин-эпохи (cytoscape/CDN) не переносится;
- LikeC4-фенсы ` ```c4 ` — другой, живой механизм (`tools/likec4_refresh.py`), не путать с html_embed

Если нужно сослаться на задачу/крон в тексте — резолв `<id>` тот же, что у task get/comment (row-id/префикс/подстрока; фоллбек на доску Crons — работает и для крон-тел).
