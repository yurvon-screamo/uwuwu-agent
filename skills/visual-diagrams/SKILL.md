# Visual Diagrams

Форма следует содержанию. Это не «кубики со стрелками», а полная выразительность веба внутри дока AFFiNE.

## Как писать

- Возьми `assets/template-vesper.html` как известно-рабочую базу (палитра, сетка шагов, карточки) и меняй содержание
- Анимации/JS — приветствуются, когда движение помогает понять (исполняется в sandbox)
- Живой пример в проде: док «Фабрика: диаграмма конвейера» (папка uwuwu)

## Возможности (проверено на нашем self-hosted AFFiNE)

- `embed_html`-блок принимает самодостаточную страницу: `<!DOCTYPE>`, `<head>`, `<style>`, `<script>`
- **JS исполняется** (sandbox-iframe): анимации, степперы, интерактивные состояния
- Рендерится в page-режиме прямо в потоке дока

## Правила выживания (единственные ограничения)

1. **Без внешних CDN** — док должен рендериться и через годы, всё инлайн
2. **Текст вокруг несёт смысл** — в export/embed диаграмма = плейсхолдер; важное дублируется словами в теле
3. Качество — ui-скилы (`rules-ui`, `architect-ui-ux`): без AI-слопа, типографика, дисциплина

## Вставка и жизненный цикл

Один механизм — markdown с фенсами, никакого отдельного diagram-API:

````
```html_embed arch
<div>…самодостаточный HTML…</div>
```
````

```bash
uwuwu-cli task body <id> --project <proj> --stdin   # или --md файл.md
```

- фенс без имени — простая вставка
- фенс с именем (`html_embed arch`) — **заменяет** прежнюю диаграмму с этим именем
- пустой фенс с именем — **удаляет** её
- перед embed ставится маркер-абзац `⁂ diagram:<имя>` (html-проп блока из API не читается — маркер адресует пару для замены)

Резолв `<id>` — тот же, что у task get/comment (row-id/префикс/подстрока; фоллбек на доску Crons — работает и для крон-тел).
