# Задачи по расписанию (планировщик cron-mode)

Планировщик исполняет задачи из файла `~/.config/opencode/cron-tasks.json`:
в момент срабатывания в сессию приходит **бриф** задачи — как новое сообщение.
Задачи переживают рестарты; пропущенный за простой триггер догоняется один раз.

## Постановка

Дозапиши задачу в массив `tasks` (write-тулом, сохранив существующие записи):

```json
{
  "tasks": [
    {
      "id": "a3f2",
      "name": "Проверка квот",
      "sessionID": "ses_…текущей сессии…",
      "prompt": "Проверь квоты через API. >80% — алерт мне, иначе тихо заверши.",
      "schedule": { "kind": "every", "intervalMs": 7200000 }
    }
  ]
}
```

`schedule` — ровно один вариант:
- `{ "kind": "once", "at": 1791800000000 }` — epoch-ms конкретного момента («напомни через 20 минут»)
- `{ "kind": "every", "intervalMs": 7200000 }` — интервал (минимум 60 000)
- `{ "kind": "cron", "expr": "0 9 * * 1-5" }` — cron 5 полей, **локальное время (Осака/JST)** — ничего не конвертируй

## Правила

- **Промпт самодостаточен.** Бриф приходит без контекста беседы (компакшн сотрёт). Пиши: что делать, что делать с результатом, кому докладывать.
- `id` — 4+ hex-символа, уникальный среди задач файла.
- `sessionID` — текущей сессии: задача живёт, пока жива сессия; умерла сессия — умерли задачи.
- После постановки кратко сообщи пользователю: что, когда первый запуск, id.
- Список живых задач — прочитай файл. Снять задачу — удали её запись.
- В брифе сказано «задача неактуальна» — удали запись сам и поясни одной строкой.

## Пиковые часы (соблюдай)

**Будни 15:00–19:00 по локальному (Осака/JST) — тяжёлые и периодические джобы по возможности не ставить и не запускать.** Переноси на утро/вечер. Одноразовые лёгкие напоминания — допустимы.
